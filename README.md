# Image-Sorting
A script created for sorting images easier, based on date.

The following libraries are used for this script:
- PIL
- glob
- os
- shutil

Therefore you should make sure to install them all before running.

When opening the scrit, locate line 8, looking like this: img_dir = "REPLACE THIS WITH THE PATH FOR THE FOLDER IN WHICH YOUR IMAGES IS PLACED" and replace the text between the quotation marks with you file path.
